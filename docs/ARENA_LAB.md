# RivetRun — Brain Arena, Lab Missions

Our grid sim, our prompts, 90 runs, 2026-10-10. Not a general model ranking. Lab Missions use a grid simulation (packages/lab), not the rail physics.

**Each question tells the brain which option the fixed rules rate as correct. These tables measure whether a model follows that under its real latency.**

Generated by `packages/brain/scripts/arena-lab.ts` · lab version 2 · prompt hash `fd730b561e` · commit fca3e98.

- Scenarios: maze, warehouse, mars, house, ctf × seeds 1001, 1002, 1003, each on the scenario's default build (Mars carries the moisture probe it needs). Seeds move the forklifts and the storm, never the map: maze, house and ctf have the same layout on every seed.
- CTF is a race against a rival robot: the lab heuristic on the same build, answering in 400 ms. A contestant slower than about that per decision loses the flag ("beaten", score 0). That is by design.
- One call per trigger, no fallback, 10 s deadline: an error, a late answer or a choice not on offer is "unanswered" and the robot keeps its command. Latency is applied in sim time.
- Fast tier and baselines only. Cost = reported tokens × the provider's official price (see docs/ARENA.md for the sources).
