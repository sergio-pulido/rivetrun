# RivetRun design v1 (mockups)

Static HTML mockups from the Claude Design canvas "RivetRun — Game Design". Reference only: implement the look in apps/web, do not import these files.

Boards:
- Main.dc.html: Home
- Workshop.dc.html: Workshop (bench, presets, slot tabs, part cards incl. Scout Drone concept)
- PartDetail.dc.html: part sheet (render, what the brain gets with/without it, specs, real part + shops)
- Assembly.dc.html: exploded view, properties, actions/senses unlocked by the build
- Brief.dc.html: mission brief + "Brief your brain" (chips + text) + priority slider
- RunMud.dc.html: run HUD, decision panel, ghosts (Mud Run)
- Result.dc.html: result, why line, Brain Duel table, score breakdown, submit/share
- RunIce.dc.html: concept, Scout Drone scanning ahead (Frozen Pass)
- RunDeep.dc.html: concept, Thruster Kit underwater (Deep Water)
- Leaderboard.dc.html: phone leaderboard
- BigScreen.dc.html: 1280×720 Room Race live view

Tokens: ground #0E1013, panel #12161B/#151920, line #232932, text #EDEFF2, muted #9AA3AE, orange #FF7A1A (action/player), cyan #3FD0E0 (brain/Jev), PCB green #2E9D63. Fonts: Chakra Petch (display), IBM Plex Sans (body), IBM Plex Mono (data).
Sample numbers, nicknames and handles in the mockups are illustrative, not measured.
