# Contract changes (additive only)

- 2026-10-09 brain: `BrainQuestion.briefing` (optional string, ≤140 chars) + `BriefingSchema`, `BRIEFING_MAX_CHARS`, `BRIEFING_PRESETS` — "Brief the brain"; only Jev reads it.
- 2026-10-09 sim: Scout Drone — `SensorKind` gains `'scout_drone'`; optional `Perception.terrainAheadSource` (`'camera' | 'scout_drone'`) and optional `BrainQuestion.lookaheadS`.
- 2026-10-09 sim: optional `PartEffects.roughGroundFactor` (locomotion; tracks soak up rough-ground entry impacts).
- 2026-10-09 sim: Deep Water — `MissionId` gains `'M6'`, `ExtraKind` gains `'thruster_kit'`, `SimEffect` gains `'bubbles'`; optional `PartEffects.requiresExtra` / `maxSwimDepthCm`; optional `SimState.waterDepthM` / `submergedDepthM` / `thrusting`.
- 2026-10-09 sim: M6 v2 — optional `Segment.currentMps`, `PartEffects.maxWadingDepthCm` (wheels 20 / off-road 35 / tracks 45), `SimState.waterCurrentMps`.
- 2026-10-09 sim: `PresetId` gains `'deep_diver'` (fourth preset, the recommended M6 build).
- 2026-10-09 sim: contracts v2 (docs/GAMEPLAY_V2.md), no behaviour yet — `Policy` gains `'human'`, `Action` gains `'jump'`, `ExtraKind` gains `'piston_jump'`; new `ControlInput`, `TrackFeature` (`Segment.feature`: ramp / gap / drop); optional `Build.batteryCells` / `wheelSizeMm` / `gearStep`, `PartEffects.jumpImpulseMps` / `cooldownS`, `SimState.heightM` / `vy` / `airborne`; `RunEvent` gains `airborne` / `landed` / `fell`.
- 2026-10-10 sim: gameplay v2 behaviour — `MissionId` gains `'M7'`; optional `Perception.gapAheadM` / `gapWidthM`; optional `Part.comingSoon`. `Segment.feature` positions: ramp = last `lengthM` of its segment, gap and drop = start of their segment.
- 2026-10-10 sim: wheel size L is 90 mm (docs/MK2_BOM.md) — `Build.wheelSizeMm` accepts `90`; `100` stays valid as the old value for L and drives identically.
- 2026-10-10 sim: obstacle geometry and strategy layer — optional `SimState.blockedBy`; `damage` event gains optional `obstacle` / `blocked` / `roughEntry` / `air`; optional `PartEffects.clearanceFactor`.
- 2026-10-10 sim: new playable parts (no schema change) — `lidar_rplidar_c1` (sensor, obstacle range 12 m, 0.11 kg) and `tof_vl53l1x_pololu` (sensor, obstacle range 4 m, 0.0005 kg) use `effects.sensor: 'ultrasonic'`, so `Perception.obstacleAheadM` / `gapAheadM` can now read up to 12 m; `brushless_motor_dfrobot_fit0441` (motor, 2.5 m/s, 1.4 N·m). Heuristic side is done in `packages/sim/src/brains.ts` (approach planning for obstacles seen beyond 3.2 m). [BRAIN] can start: Jev question builder and /api/decide cache key.
- 2026-10-10 sim: Brain v3 + gameplay v3 types (behaviour follows) — new `sensing.ts`: `GAMEPLAY_VERSION`, `SensorSource`, `Observation`, `Trigger` (`TriggerKind`, `TriggerCause`), `SeenHazard` / `SeenGap` / `SeenTerrain`, `ScanZoneView`; `BrainQuestion` gains optional `observation`, `cause`, `gameplayVersion`; `LookaheadEntry.projectedFinishPct`; `Action` gains `'coast'`, `'brake_soft'`, `'scan'`; `DecisionTrigger` gains `'energy'`, `'actuator'`; `ControlInput.throttle` / `brake` accept 0..1 or a boolean; `DecisionLog` on the `decision` RunEvent (`log`, `advisory`) and on `DecisionRecord`; `damage` event gains `blind`, `label`; `Outcome.breakdown`; `Mission.scanZones` (`ScanZone`); `PartEffects.source`.
- 2026-10-10 brain: optional `GhostTrace.log` (`DecisionLog[]`, stamped with the ghost's sim clock) — the telemetry console replays Jev's decision thread in sync with the ghost.
- 2026-10-10 sim: Brain v3 behaviour — every BrainQuestion carries `observation` and `cause`; decisions are requested only on triggers (no clock: `interval` is never emitted), the last command holds, and `BrainDecision.latencyMs` is applied as sim time in headless runs; live runs no longer slow down while the brain thinks (`slowMo` defaults to false); `decision` events and `DecisionRecord` carry `log`; Drive mode emits advisory `decision` events; `damage` events carry `blind` / `label`. `TriggerCause` gains `'stopped'`. Measured, heuristic, seed 1001, 7 missions × 4 presets: 12.0 decisions per run (was 21.4, 62 % of them the clock).
- 2026-10-10 sim: gameplay v3 P1 behaviour — analog `ControlInput` (throttle ≥ 0.85 full / ≥ 0.5 steady / ≥ 0.15 ease / else coast; brake ≥ 0.6 hard / ≥ 0.1 soft; nothing held = coast); wheelspin (drive asking over 1.1× the grip leaves 70 % of it; climb mode has traction control); impact damage ∝ (v − v_safe)², v_safe 0.6 m/s × 1.5 with a bumper × clearance (0.8–1.3); scan zones (M1: 1, M3: 2, M7: 3 — stop under 0.1 m/s for 1.5 s, a miss adds 10 s, a centred stop adds 15 points); `SimState.scan` / `scansDone` / `scansMissed`; `Outcome.breakdown` (+ `scanPenaltyS`, `scanBonus`, `reactions`). M7 is now "Earthquake Rescue". M6 star threshold 500 → 450.
- 2026-10-10 sim: energy tuning — drive draw × 3.5 (thrusters × 1.2); throttle levels differ in efficiency (per metre: steady ≈ 70 % of full, ease ≈ 57 %; coast and brakes draw nothing; climb mode power 1.4 → 0.7); small battery 0.5 → 0.3 Wh. Measured on the mission's fixed drive seed, heavy build on the small battery: M5 (tracks, torque motor, camera + ultrasonic, case + bumper) full throttle runs out at 90 % of the track, steady finishes with 14 % left, heuristic finishes with 12 %; M6 (Deep Diver parts, small battery) full throttle runs out at 90 %, steady finishes with 7 %, heuristic with 6 %. Preset finish rates on M1–M7 are unchanged; scores drop by the extra energy used.
- 2026-10-10 sim: telemetry — new RunEvent `observation` { t, observation, control? { throttle, brake, action } }, emitted every 4 steps (5 Hz) by runController and driveController; Drive-mode reactions on `Outcome.breakdown.reactions` ({ t, xM, label, cause, humanS | null }: first control change within 3 s of a perception or body trigger). M6 star threshold 450 → 400.
